тесты. Отчёты агентов — в истории сессии; здесь сводка со сквозными приоритетами.

## Важно (выборочно, по зонам)

- **Приватность:** телеметрия удалённого ребёнка остаётся в очереди; удаление аккаунта без
  подтверждения сервера; `heard` в типе пропускает текст; сводное состояние хранится
  бессрочно; срок для неактивных аккаунтов; лимиты только по IP; Sentry прокси — заголовок
  `authorization`; для ребёнка без облака согласие на ИИ на сервере не проверить.
- **Бэкенд:** замок синхронизации без таймаута; `child_state` без версии; часы назад
  блокируют запись отзыва; нет оркестратора урока; навыки с двух устройств затирают друг
  друга; миграции трогают `auth.users` — проверить на ветке Supabase; индексы под удаление
  и ретеншн; `abaSession.ts` 1517 строк — разбить; тройной `shuffle`.
- **ABA:** 2 провала → L3 с любого уровня слишком жёстко; `do_action` сплошным блоком —
  простая дискриминация; у эхоики SD сливается с моделью; шейпинг не определён; градаций L2
  нет в коде; `device_loudness` двигает критерий у любого формата; набор на 5–6 длиннее
  нормы; у специалиста нет рычагов (смена фазы, пауза).
- **Контент:** спираль мешает повторению; «освоено» слишком быстро и не теряется; у
  малышей очередь повторений растёт; часть тем не измерима шестью форматами; 9–10
  объединяет 3 и 4 класс без порядка; `rapid-guessing` срабатывает на субитизацию; гард не
  ловит машинно проверяемое.
- **Дизайн и UX:** «выбрано» тремя способами, пунктир в шести значениях; `*Ink` не
  проходит контраст на `surfaceAlt`/`surfaceSunken`; звёзды атласа на жёлтом регионе;
  кроп Tali не зафиксирован; `RegionId` `workshop`/`logic`; панель взрослого ABA под
  стимулом — случайные оценки; выход из ABA 800 мс; гейт родителя и автозакрытие 2 мин;
  Dynamic Type в родительском разделе; caption 14 для семилеток; нет экрана конца сессии;
  «+ Добавить» профиль в обход согласия.

## Противоречия — решено владельцем 2026-10-01

- **design-lead против child-ux-specialist:** подушка у Tali, пузыря и карточки стимула
  (UX — не нужна); кнопки слоя выхода (дизайн — равный вес, UX — защищает позиция);
  «выбрано» (UX — правило «вдавлено = выбрано»).
- **ABA-методист против своего прошлого совета:** «2 провала → сразу полная модель»
  введено по его рекомендации, теперь — «на ступень, но не ниже уровня, несущего ответ».
- **Контент против решения по зазору:** принято 1 / 3 дня для коробок 3 / 4; методист
  предлагает 3 / 7 и возврат из коробки 4 в 3 при подсказке.
- **ABA против набора «покажи…»:** на 5–6 не больше 3 целей в наборе.
