# Отложенные скиллы

Скиллы, которые решено добавить позже — когда начнётся работа, которую они делают.
Краткая таблица триггеров лежит в `CLAUDE.md` («Скиллы»); здесь — что каждый должен
уметь, чтобы его можно было написать без повторного анализа.

Когда скилл добавлен, его раздел отсюда удаляется, а строка в `CLAUDE.md` переезжает
из «Отложенных» в «Установленные».

Своё пишется в `.claude/skills/<имя>/SKILL.md` по образцу `lesson-author`, удобно —
через `anthropic-skills:skill-creator`.

---

## Свои скиллы

### format-screen — экран одного из шести форматов

**Когда предлагать:** начало реализации экранов `choose`, `point`, `match`, `order`,
`group`, `build`; «сделай экран задания», «реализуй формат».

**Что должен держать:**
- «ткнул → ткнул» вместо drag; отмена одним касанием;
- зона нажатия ≥ 60×60 pt, зазор ≥ 16 pt; один основной выбор на экране;
- озвучка каждого элемента по тапу (ключ локали = путь к `voice/<язык>/<ключ>.m4a`);
- механика ошибки из `FORMATS.md`: первая убирает заведомо неверный элемент и даёт
  `hintKey`, вторая показывает ответ и требует подтверждающий тап; повтор того же
  экрана запрещён;
- защита от двойного тапа по «Проверить» — аудит нашёл проскок обратной связи;
- только токены `src/design/tokens.ts`; состояния различаются контуром и силуэтом,
  не цветом и не `opacity`; тёмная, calm и focus;
- схема «выбрал → проверил»: промах пальцем не засчитывается как ошибка;
- тесты на механику ошибки и на сужение для каждого формата.

**Проверка:** `design-lead`, затем `child-ux-specialist` — последовательно.

### tali-lines — реплики Tali

**Когда предлагать:** «напиши реплики Tali», работа с `companionSituations.ts`,
завязки уроков, сюжетные события арки.

**Что должен держать:** ситуации и подстановки из `TALI.md`; по четыре варианта на
ситуацию и отсутствие заметных повторов; перекос прежнего корпуса (167 реплик на
верный ответ, 12 на ошибку) не повторять; на ошибку Tali озадачен вместе с ребёнком,
а не разочарован; разные роли Tali, а не вечно ошибающийся; реплика звучит вслух
пятилетке. Сюжетные события — одно на завершённую тему, каждый класс — законченная
арка (`REBUILD.md`, «Сюжет и учебники»).

**Проверка:** `curriculum-content-reviewer`.

### asset-pipeline — ассеты Recraft и Nano Banana

**Когда предлагать:** генерация новых иконок, предметов к заданиям, жителей регионов;
«добавь картинку», «нужен ассет».

**Шаги:** промпт по `ASSETS.md` со ссылкой на сохранённый Style → имя файла по
конвенции → `npm run assets:normalize-svg` → запись в `src/assets/registry.ts` →
`registry.test.ts`. Приёмка: прозрачный фон, без текста в картинке, один объект на
файл, контур одинаковой толщины, SVG ≤ 300 КБ, силуэт узнаётся в чёрной заливке на
24 px. Ни растровых иконок, ни эмодзи.

### proxy-route — новый роут прокси

**Когда предлагать:** «добавь эндпоинт / роут в прокси», новый `/api/*`.

**Шаги:** Supabase JWT, Zod-схема на тело, rate limit; всё про ребёнка —
`supabaseAsUser(jwt)`, не `supabaseAdmin`; согласие — `hasConsent`; ключи провайдеров
только на сервере; наружу в ИИ — минимум (код ситуации и сказанное ребёнком, без
имени, возраста, id); Vitest-тест на 401, 400, 429 и отказ без согласия.

**Проверка:** встроенный `security-review` + `child-privacy-compliance`.

### voice-build — озвучка при сборке

**Когда предлагать:** начало озвучки корпуса, TTS, ElevenLabs, «сгенерируй голос».

**Что держать:** адрес файла = ключ локали, `voice/<язык>/<ключ>.m4a`; генерация при
сборке контента, а не в приложении; уникальные ключи, а не вхождения; 32 kbps;
отчёт по недостающим файлам. Опора — существующие `fetch-lesson-audio-elevenlabs.mjs`
и `generate-lesson-voice-map.mjs`, переведённые на новую схему. Ключ ElevenLabs в
приложение не попадает.

## Готовые внешние скиллы

Перед установкой прочитать содержимое. Если скилл противоречит `CLAUDE.md`, прав
`CLAUDE.md`.

| Скилл | Когда предлагать | Установка |
|---|---|---|
| Expo Skills (официальный, `expo/skills`) | EAS-сборка, обновление SDK, `expo-local-authentication`, нативный модуль, конфиг `app.json` | `/plugin install expo@claude-plugins-official` |
| Supabase Agent Skills (`supabase/agent-skills`) | подключение облачного Supabase, накат миграций на ветку, Realtime, производительность запросов | `npx skills add supabase/agent-skills` |
| Vercel `react-native-skills` (`vercel-labs/agent-skills`) | анимация Tali кодом (Reanimated), карта-лента, производительность списков | из `vercel-labs/agent-skills`, скилл `react-native-skills` |
