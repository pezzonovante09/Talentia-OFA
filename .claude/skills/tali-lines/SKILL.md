# Реплики Tali

Производит реплики компаньона, которые звучат постоянно: банк — основной путь, а не
запасной (TALI.md, «Банк — не запасной путь»). Источник правил — **TALI.md**; этот скилл
задаёт порядок работы и не повторяет правила подстановок — они меняются, действует то, что
в TALI.md сейчас.

## 0. Перед началом

1. Прочитай TALI.md целиком: «Роли Tali», «Ситуации», «Подстановки», «Форма обращения к
   ребёнку», «Без заметных повторов», «Чего Tali не делает офлайн».
2. Прочитай `talentia-mobile/src/domain/companionSituations.ts` (список `SITUATIONS`,
   `COMPANION_SLOTS`, `OBJECT_CONSTRUCTIONS`, `VARIANTS_PER_SITUATION`, `lineKeyFor`) и гард
   `talentia-mobile/src/i18n/__tests__/companionLines.test.ts` — что он ловит машинно.
3. Правка **правила** (новая подстановка, новая конструкция, новая ситуация) — сначала агент:
   `localization-qa` для подстановок и форм на трёх языках, `curriculum-content-reviewer`
   для ситуаций и голоса. Порядок: TALI.md → `companionSituations.ts` → гард с фикстурой на
   новое правило (годная и негодная реплика) → реплики. Не наоборот.
4. Сырьё для `correct-*` — прежние 167 реплик только в git (TALI.md, «Сырьё для банка»);
   переписывать, а не копировать; en и ky оттуда не брать.

## 1. Голос

- Реплика звучит вслух пятилетке: короткая фраза, без скобок, сокращений и цифр там, где
  нужно слово. Длина — как у подсказки (`lessonLimits.ts`): ru не больше
  `TEXT_LIMITS.hintChars` (36 знаков), en и ky — не больше `BUBBLE_CHARS`; у банка гард
  длину пока не проверяет (раунд 2, `localization-qa` В2) — считай сам.
- **Уместность, а не новизна**: реплика попадает в момент (серия, «раньше не давалось»,
  число и предмет текущего задания), а не общее «Молодец».
- На ошибку Tali озадачен **вместе** с ребёнком, а не разочарован; без «неправильно», без
  оценки ребёнка. Перекос прежнего корпуса (167 на верный, 12 на ошибку) не повторять:
  ошибке, показу ответа и поведению — столько же внимания, сколько успеху.
- Роли по урокам темы — из TALI.md: Tali не вечно ошибающийся; в ABA не ошибается никогда.
  Житель региона — только заказчик в завязке; похвала и подсказка — только Tali.
- Tali о себе в ru — в мужском роде («я перепутал»).

## 2. Форма обращения к ребёнку

- **Основная реплика безродовая** и есть всегда: «У тебя получилось!», а не «ты справился».
  Без прошедшего времени о ребёнке, без «сам / сама».
- Родовая (`_f` / `_m`) — необязательная надстройка только в ru и только при безродовой
  основе того же номера; в en и ky родовых ключей нет.
- Имя `{{name}}` — только обращением в начале или в конце, у каждой реплики с именем есть
  вариант без имени. Форма обращения и имя в ИИ не уходят.

## 3. Банк

- Ключи: `companion.<ситуация>.<n>` (n = 1…`VARIANTS_PER_SITUATION`), родовые и plural —
  суффиксами по TALI.md, «Подстановки».
- По четыре варианта на ситуацию, заметно разных: не один шаблон с заменой слова.
  Проверь каждую ситуацию подряд — «вариант звучит снова после всех остальных», повтор
  начала фразы в двух вариантах из четырёх уже слышен.
- Подстановки — только из `COMPANION_SLOTS`, предмет и регион — готовыми формами из
  словаря по закрытому списку конструкций; число — по правилу TALI.md (какое оно сейчас —
  смотри там, это место меняется).
- Пишем только **ru**. en и ky не заполняются, пока владелец не снимет «локализация после
  контента»; ky — всегда с носителем (TALI.md, `localization-qa`).

## 4. Сюжетные события

Одно событие на завершённую тему, порядка 40 на всё; класс — законченная арка, ребёнок
входит со своего класса и получает короткое «что было раньше» (REBUILD.md, «Сюжет и
учебники: два слоя»). Событие не требует от ребёнка чтения и не обещает того, чего нет в
следующей теме. Схемы ключей и места, где событие звучит, пока нет: перед первым событием
согласовать с `curriculum-content-reviewer`, записать в TALI.md и сюда.

## 5. Проверка

Из `talentia-mobile/`:

```bash
npx jest src/i18n src/domain/__tests__/companion.test.ts
npm run typecheck
```

Гард ловит подстановки, plural-наборы, аффиксы, имя, род ребёнка. Глазами — то, что гард не
видит: уместность в момент, озадаченность вместо разочарования, разница четырёх
вариантов, звучание вслух. Затем — ревью `curriculum-content-reviewer` (голос, ситуации,
возраст) и `localization-qa` (подстановки, род, длина). Правки из ревью вносит основной
поток.

## 6. Отчёт

Какие ситуации и сколько реплик добавлено, какие правила менялись (TALI.md, код, гард —
с фикстурами), результаты команд, что ждёт носителя или решения владельца.
