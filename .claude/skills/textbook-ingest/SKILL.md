# Разбор источника программы

Превращает источник в заметки, из которых `lesson-author` пишет уроки. Один источник —
один файл `docs/sources/<предмет>-<класс>.md`.

## Главное правило: темы берём, формулировки — нет

Авторским правом защищена **формулировка** задания и его оформление: конкретная задача
«у Маши было пять яблок» вместе с текстом и картинкой. Перечень тем, порядок и
требования к умениям — содержание стандарта и не защищены (см. `CURRICULUM.md`,
«Из чего берём темы»).

Поэтому в заметки **не попадают**: тексты задач и упражнений, дословные правила
длиннее одной фразы, иллюстрации, имена персонажей учебника. Если пример нужен,
чтобы показать тип задачи, — опиши тип своими словами («сравнение двух групп
предметов без счёта»), а не перепиши задачу.

## Шаги

1. **Паспорт источника.** Спроси, если не сказано: предмет, класс, язык, год, чей
   документ (стандарт КАО, учебник какого издательства, план школы). Стандарт
   ценнее учебника: по нему построена сетка. Учебник уточняет порядок и глубину.
2. **Извлечение.** Для PDF используй скилл `anthropic-skills:pdf`. Фото страниц
   распознаются хуже — отмечай места, где текст прочитан неуверенно, пометкой
   `[неразборчиво, с. N]`, а не угадывай.
3. **Привязка к сетке.** Каждую найденную тему сопоставь с клеткой `CURRICULUM.md`
   (регион × полоса × тема). Три исхода, все в отчёт:
   - совпадает — дополни заметку навыками;
   - в источнике есть, в сетке нет — предложи, не добавляй сам;
   - в сетке есть, в источнике нет — отметь, откуда она тогда взялась.
   Особо следи за сдвигом по классам: сетка уже однажды спаслась проверкой
   первоисточником (1 класс КР — числа до 100, а не до 20).
4. **Навыки.** Для каждой темы — список навыков в формате поля `skill` из
   `src/types/task.ts` (kebab-case латиницей, `count-to-5`). Навык узкий: его можно
   проверить одним заданием за 20 секунд. Если в `src/content` навык уже есть, бери
   тот же id, а не заводи синоним.
5. **Что пригодится автору уроков** — для каждой темы:
   - что ребёнок должен уметь к концу (из стандарта, своими словами);
   - границы: до какого числа, какие слова, чего ещё нет в этом классе;
   - типичные ошибки детей — из них получаются неверные варианты и подсказки;
   - какие из шести форматов (`FORMATS.md`) ложатся естественно;
   - зависит ли тема от языка обучения (`instructionLanguages`).

## Формат файла

```markdown
# <Предмет>, <класс> — <документ>

Источник: <название, издатель/ведомство, год>, страницы <…>.
Разобрано: <дата>.

## <Тема> → <регион> / <полоса> / <тема в CURRICULUM.md>

- Цель: …
- Навыки: `skill-a`, `skill-b`
- Границы: …
- Типичные ошибки: …
- Форматы: choose, order …
- Страницы: 12–15

## Расхождения с сеткой
…
```

## Отчёт пользователю

Сколько тем разобрано, сколько совпало с сеткой, список расхождений с предложением
по каждому и какие места прочитаны неуверенно. Предложи следующий шаг:
`lesson-author` на первую тему.
