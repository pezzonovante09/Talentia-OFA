# Автор уроков

Производит уроки для одной темы из `CURRICULUM.md`: обычно три урока, файл
`talentia-mobile/src/content/<регион>-<полоса>.ts` и ключи в
`talentia-mobile/src/i18n/locales/ru.json`. Образец — `src/content/numbers-5-6.ts`:
прежде чем писать, прочитай его целиком и держи тот же стиль, включая
комментарий над уроком о педагогическом замысле.

Прежний корпус из 611 заданий сломался на авторском конвейере: импорт-скрипты писали
в общие ключи и ничего не проверяли. Этот скилл существует, чтобы так не вышло снова,
поэтому шаги проверки не пропускаются даже на одном задании.

## 0. Предусловия

1. Прочитай: `FORMATS.md` (разделы «Ошибка», «Язык», «Правила на корпус»), нужный
   регион в `CURRICULUM.md`, «Устройство урока» в `REBUILD.md`, `src/types/task.ts`.
2. **Гард на новую схему.** `src/data/__tests__/corpus.test.ts` исторически проверяет
   `src/data/worlds.ts` — старую схему. Проверь, импортирует ли какой-нибудь тест
   `src/content`. Если нет — **остановись и скажи пользователю**: писать уроки без
   гарда — ровно то, что сгубило прежний корпус. Предложи поручить `qa-engineer`
   перевести гард на `src/types/task.ts` с правилами из раздела 3 ниже.
3. Источник темы — предметный стандарт КАО (см. «Источники» в `CURRICULUM.md`) или
   заметки от скилла `textbook-ingest` в `docs/sources/`. Формулировки заданий из
   учебника **не копируются**: защищена формулировка, а не тема. Пишем свои.

## 1. План темы — до первого задания

Покажи пользователю план и дождись согласия, если тема новая:

- навыки темы (`skill`, kebab-case, латиницей: `subitize-1-3`, `compare-more-less`);
  один навык живёт в нескольких уроках — это нужно интервальному повторению;
- для каждого урока: цель одной фразой, навыки, раскладка форматов по заданиям,
  роль Tali в завязке;
- прогрессия внутри темы: урок 1 узнаёт, урок 3 применяет.

## 2. Устройство урока

| Полоса | Заданий | Подача |
|---|---|---|
| `5-6` | 4–5 (6–8 минут) | только `picture`, каждый элемент озвучен |
| `7`, `8` | в `REBUILD.md` не зафиксировано — спроси; `CURRICULUM.md` считает 4–6 | `picture`, текст подписывает картинку |
| `9-10` | 8–10 | `picture` или `text` |

- **Завязка** (`hook`): 10–20 секунд голосом, одна реплика Tali, поза из
  `'hello' | 'found' | 'point' | 'cheer' | 'puzzled' | 'write'`.
- **Роль Tali меняется.** Аудит нашёл, что Tali ошибался в 100% сценариев. Внутри
  темы чередуй: ошибается — ребёнок поправляет; знает и показывает; разбираются
  вместе; просит помощи в своём (ти-рекс с крошечными ручками не дотянулся, не
  удержал, не сосчитал на пальцах). Окончательное правило ролей — открытый вопрос
  №1 в `REBUILD.md`; если он уже решён, следуй решению.
- **Атлас** (`atlasEntryKey`): одна фраза о том, что установлено уроком. Короткая:
  полный корпус атласа пишется в конце.
- Форматы и их минимальные полосы — `FORMAT_MIN_BAND` в `task.ts`. `build` только с 7.
- Ни одного drag: `match`, `order`, `group` работают «ткнул → ткнул».

## 3. Инварианты — каждое задание, без исключений

1. Ровно один верный вариант в `choose`; 2–4 варианта; `id` вариантов уникальны в задании.
2. У `point` радиус зоны `r ≥ 0.1`, координаты в долях кадра (0–1), ровно одна
   верная зона.
3. `skill` и `hintKey` есть у каждого задания. Подсказка — **одна** строка, которая
   помогает сузить выбор, а не называет ответ. Вторую ступень (показ ответа)
   приложение строит само — её не пишут.
4. Подсказка осмысленна после удаления одного неверного варианта: после первой
   ошибки задание сужается, а не повторяется.
5. В тексте нет ответа: ни `(ответ: N)`, ни формулировок, из которых он читается.
6. Не больше двух заданий одного формата подряд; минимум два разных формата в уроке;
   доля `choose` по корпусу ≤ 50%.
7. На `5-6` у каждого варианта есть и картинка (`shape` или `image`), и `labelKey`
   для озвучки.
8. `lang` только там, где содержание само есть язык (английское слово, русский слог).
   Тема, существующая только при одном языке, получает `instructionLanguages`.
9. Для счёта — `shape` + `count` (`stone | berry | leaf | dot`), а не новая картинка.
   Сцена для `point` — панорама региона (`region-numbers` и т. п.), пока иное не нужно.
   Новый `image` — только если без него нельзя; тогда допиши его в список
   недостающих ассетов в отчёте.

## 4. Ключи локали

- Схема: `content.<регион>.<урок>.<tN>.prompt | hint | stimulus`,
  `content.<регион>.<урок>.title | hook | atlas`. Общие подписи —
  `content.common.*`, **только если смысл тот же везде** («два» — да; «К
  прилагательному» под ключом `opt_yes` — никогда: так прежний корпус и сломался).
- id: по образцу `nv-count-l1-t1` (регион · тема · урок · задание). Для регионов без
  префикса предложи короткий и допиши его сюда.
- Пишем только `ru`. Локализация снята с повестки до финала контента — en/ky не
  заполняются.
- Текст читается вслух пятилетке: короткие фразы, без скобок, сокращений и цифр там,
  где нужно слово.

## 5. Проверка — перед тем как сказать «готово»

Из `talentia-mobile/`:

```bash
npx jest src/data src/content   # гарды корпуса
npm run typecheck
npx eslint src/content
```

Затем предложи пользователю ревью: `curriculum-content-reviewer` (ясность,
прогрессия, возраст). Для пилота Числовой долины — ещё и `child-ux-specialist` на
поток урока. Правки из ревью вносит основной поток.

## 6. Отчёт

Коротко: какие уроки и навыки добавлены, раскладка форматов по урокам, роли Tali,
результаты команд, какие ассеты понадобятся, какие решения ты принял сам и они
требуют подтверждения.
