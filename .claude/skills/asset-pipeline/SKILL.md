# Ассеты

Картинки генерирует **владелец** (Recraft / Google AI Studio, бюджет №139). Скилл пишет ему промпты, а пришедшие
файлы принимает, кладёт и регистрирует. Ни один ассет не попадает в экран мимо реестра: гард `registry.test.ts`
сверяет реестр с папками, и «висящий» файл или ссылка в никуда — красный тест.

## 0. Что за ассет — и каким инструментом

| Что | Инструмент | Формат | Куда |
|---|---|---|---|
| стимул ABA (плита пробы `match`, `identify`) | Recraft, Style Lock | **SVG, только вектор** — на экране пробы растр запрещён (ABA.md «Визуальный язык») | `assets/images/aba/stimuli/aba-obj-<имя>.svg` |
| предмет к уроку | Nano Banana (ASSETS.md шаг 5) | WebP 768×768 | `assets/images/tasks/` |
| иконка интерфейса | Recraft | SVG одноцветный (ASSETS.md шаг 4) | `assets/icons/ui-<имя>.svg` |
| житель региона, панорама, Tali | Recraft по образцу | SVG | по ASSETS.md шаги 2–3 |

Формы и цвета (`aba-shape-*`, `aba-color-*`) — не ассеты: рисуются кодом в `src/ui/aba/`, файлов нет.

## 1. Промпт

1. Прочитай ASSETS.md: шаг 0 (палитра, модели, прозрачный фон), «Главное правило: плотность — это узор», нужный шаг,
   «Приёмка». Палитра — та же, что в `scripts/check-svg.mjs` `PALETTE`.
2. Один объект — один файл, один промпт. Для стимулов ABA — нейтральная поза предмета, три четверти или анфас,
   без фона, без тени, без текста, контур `#2A1A12` одинаковой толщины, плоские заливки, ступени тона вместо
   светотени; предмет узнаётся силуэтом в чёрной заливке на 24 px. Стимул **не похож на позиции каталога
   подкрепителей** (`src/content/aba/reinforcers.ts`, поле `classes`) и не жёлтый/оранжевый, как жетон.
3. Промпты — списком в документе партии `docs/assets/<партия>.md`: таблица «id файла · что · промпт · статус».
   Владелец генерирует, файлы кладёт в `talentia-mobile/scripts/input/`.

## 2. Приёмка пришедших файлов

1. Имя — по таблице партии (латиница, дефисы, префикс вида).
2. `npm run assets:check -- scripts/input` — размер ≤ 300 КБ, есть viewBox, нет текста, растра, градиентов,
   фильтров и белой подложки, цвета из палитры. Красное — назад владельцу с причиной, а не правка руками.
3. Глазами (ASSETS.md «Приёмка»): плотность узором, а не анатомией; прозрачный фон на цветной подложке;
   контур как у соседних ассетов; силуэт на 24 px.
4. Принятое — в целевую папку из таблицы шага 0; статус в документе партии — «принято».

## 3. Реестр и гард

1. `src/assets/registry.ts`: статический `import` файла и запись в нужный словарь (`ABA_STIMULI`, `ICONS`…).
   Пока файла нет, у стимула `svg: null` — экран рисует заглушку-силуэт (`src/ui/aba/`), гард пропускает
   `null` только у id из документа партии со статусом «ждём».
2. `npm test -- src/assets` и гард контента, который ссылается на ассет (`src/content/__tests__/abaTargets.test.ts`
   для стимулов ABA).
3. Коммит: ассеты, реестр и документ партии — одним коммитом.

## Чего не делать

- Не генерировать и не рисовать ассет самому в коде «пока нет» — только заглушка из `src/ui/aba/`.
- Не класть растр в стимулы ABA и не брать старые `assets/images/aba/*.webp` (прежняя версия).
- Не подгонять цвет в коде, если модель увела оттенок, — перегенерация.
