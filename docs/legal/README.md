# docs/legal — черновики для юриста

Черновики политики конфиденциальности, условий использования и страницы удаления данных, ru и en.
**Не публикация.** Тексты написаны по фактической реализации (`PARENT.md`, `ARCHITECTURE.md`,
`talentia-mobile/src/services/local/`) для версии 1, которая уходит **без облака и без ИИ**.
Всё, чего в v1 нет (облако, Tali через ИИ, голос, специалист), в текстах названо «не
включено»; когда функция появится, документ пересматривается до релиза этой функции.

Места, где нужно решение владельца или юриста, помечены `[[ВЛАДЕЛЕЦ: …]]` (`[[OWNER: …]]` в en).
Пока хотя бы одна пометка осталась, тексты публиковать нельзя. Кыргызский вариант не
подготовлен: нужен перевод носителем после утверждения ru.

| Файл | Что |
|---|---|
| `privacy-policy.ru.md`, `privacy-policy.en.md` | политика конфиденциальности |
| `terms-of-use.ru.md`, `terms-of-use.en.md` | условия использования |
| `account-deletion.ru.md`, `account-deletion.en.md` | страница удаления данных и аккаунта |

Фактические утверждения, которые надо перепроверить по коду перед публикацией (экранов ещё
нет, поведение взято из спецификаций и слоя данных): локальный срок хранения журналов
12 месяцев (`RETENTION_MONTHS`), запрет резервной копии (`plugins/withNoDataBackup.js`), PIN
хранится хешем с солью в SecureStore, разрешения `app.json` пусты, рекламы и аналитики нет,
имя ребёнка необязательное и только на устройстве, экспорт и удаление доступны за PIN.

## Для владельца: лишняя зависимость в сборке v1

`@supabase/supabase-js` указан в `talentia-mobile/package.json` (dependencies), но нигде в коде
мобильного приложения не импортируется и не вызывается (поиск по `talentia-mobile` без
`node_modules`: совпадения только в `package.json` и `package-lock.json`). Раз v1 без облака, пакет
стоит убрать из сборки v1: иначе он расходится с заявлением «данные не уходят с устройства» в
декларациях сторов и раздувает бандл. Это решение владельца; `package.json` не менялся.
