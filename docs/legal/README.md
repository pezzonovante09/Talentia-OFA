# docs/legal — черновики для юриста

Черновики политики конфиденциальности, условий использования и страницы удаления данных, ru и en.
**Не публикация.** Тексты написаны по фактической реализации (`PARENT.md`, `ARCHITECTURE.md`,
`talentia-mobile/src/services/local/`) для версии 1, которая уходит **без облака и без ИИ**.
Всё, чего в v1 нет (облако, Tali через ИИ, голос), в текстах названо «не включено»; когда функция
появится, документ пересматривается до релиза этой функции. Передача записей ABA специалисту есть
только файлом, руками родителя через системный лист «Поделиться» (№168, вопрос 67) — см. версию 3
текста `aba_processing` ниже.

Места, где нужно решение владельца или юриста, помечены `[[ВЛАДЕЛЕЦ: …]]` (`[[OWNER: …]]` в en).
Пока хотя бы одна пометка осталась, тексты публиковать нельзя. Кыргызский вариант не
подготовлен: нужен перевод носителем после утверждения ru.

| Файл | Что |
|---|---|
| `privacy-policy.ru.md`, `privacy-policy.en.md` | политика конфиденциальности |
| `terms-of-use.ru.md`, `terms-of-use.en.md` | условия использования |
| `account-deletion.ru.md`, `account-deletion.en.md` | страница удаления данных |

Фактические утверждения, которые надо перепроверить по коду перед публикацией (экраны есть с
2026-10-24; поведение сверено с кодом в контрольном аудите 2026-11-09 — перепроверить на итоговой сборке): локальный срок хранения журналов
12 месяцев (`RETENTION_MONTHS`), запрет резервной копии (`plugins/withNoDataBackup.js`), PIN
хранится хешем с солью в SecureStore, разрешения `app.json` пусты, рекламы и аналитики нет,
имя ребёнка необязательное и только на устройстве, экспорт и удаление доступны за PIN (экрана экспорта
для родителя пока нет — см. блокер ниже).
