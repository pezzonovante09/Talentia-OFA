# Оценка ABA в Talentia и связь со школьной программой (2026-11-17)

Оценивали агенты `aba-pedagogy-specialist` (вся ABA-часть) и `curriculum-content-reviewer` (связь с программой 0–4
классов) по концепции №204. Это не живой специалист: всё ниже — предложения и вопросы к встрече (этап 13), процедура
заморожена до неё (№198). Ссылки на код и ABA.md — в отчётах агентов; здесь простыми словами.

**Вердикт.** Ядро ABA сделано правильно и лучше многих коммерческих приложений. Есть два места, где ребёнку может быть
плохо, — их стоит обсудить со специалистом первыми.

## Что хорошо

- Навык разбит на малые шаги: одинаковые из 2 → из 3 → форма, цвет.
- Новое учится без ошибок: сначала полная подсказка, потом она постепенно убирается; приложение само замечает,
  если ребёнок привыкает к подсказке.
- Жетон — только за ответ без лишней помощи; жетоны не отнимаются; награды сменяются, чтобы не надоедали.
- Знакомство с жетонами: сначала жетон даётся просто так, доска растёт 1 → 2 → 3.
- Карточка «перерыв» — настоящая просьба ребёнка; её всегда выполняют, задание потом возвращается.
- Данные подробные: как ребёнок ответил, с какой подсказкой; проверка переноса на новые картинки; повторение освоенного.

## Что плохо — по серьёзности

1. **Вред: занятия без единой награды.** После знакомства с жетонами идут проверочные занятия, где жетонов нет вообще
   (второе занятие — 13 заданий и ничего). Ценность жетона, которую только что создали, гаснет. *Предложение:* в
   проверках давать награду не за ответы, а за участие, или встраивать проверку в обучающее занятие.
2. **Вред: касанию образца никто не учит.** Пока ребёнок не коснулся верхней картинки, нижние не нажимаются. Ребёнок,
   который сразу нажал верную внизу, не получает ничего, а в данных — «нет ответа». На первой проверке это провал и
   откат на 2–3 занятия (то, что случилось на вашем тесте). *Предложение:* учить касанию образца отдельным шагом, как
   карточке «перерыв»; «нет ответа» на проверке не считать провалом.
3. **Окно 5 секунд** на касание и на выбор может быть мало медленным детям: их самостоятельные ответы станут
   «подсказанными». Специалист пока не может это окно поменять.
4. **Дома никто не проверяет взрослого.** Родитель без обучения покажет пальцем и не нажмёт «Была подсказка» — данные
   будут лучше, чем на самом деле.
5. В задании «форма» цвет фигур совпадает с цветами задания «цвет» — ребёнок может ориентироваться на цвет.

## Что добавить — по порядку

1. **Просьбы** («ещё», «хочу [награду]») карточкой в приложении — главный навык для этих детей, снижает проблемное поведение.
2. **«Покажи, где мяч»** (узнавание по названию) — логика уже есть, нужен только контент.
3. **Подражание движениям и выполнение инструкций** (засчитывает взрослый), затем **называние**.
4. **Перенос в жизнь:** отметка «проверили на настоящих предметах / с другим взрослым».
5. **Проблемное поведение:** простая запись «что было до — что сделал — что было после» для специалиста.
6. **Обучение родителя:** короткий курс «объяснение — показ — пробное занятие — обратная связь» и проверка готовности.
7. **Читаемый отчёт специалисту** вместо машинного файла.

## Что убрать или упростить

- Длинная цепочка перед первым обучением (знакомство → перерыв → проверка → первые пробы): при центре стартовое
  задание может выбрать специалист, проверку оставить семьям без специалиста.
- Скрыть из домашнего режима бумажную проверку двух наблюдателей и физическую подсказку — для «найди такую же» не нужны.
- Родителю — одно правило вместо многих: «Не показывайте и не называйте ответ. Помогли — нажмите „Была подсказка“».

## Сколько можно «игры»

**Можно:** Tali и сюжет между блоками и на перерыве; Tali как одна из наград; карта как расписание занятия («ещё 2
блока») — предсказуемость детям с РАС полезна; продвижение по сюжету как награда за полную доску.
**Нельзя:** что-либо между заданием и ответом; очки, звёзды, «уровни» за каждую попытку (обесценят жетон); потеря
чего-либо, таймеры; сюжет в обход доски жетонов; всё, что удлиняет занятие. Коллекции и наклейки сейчас запрещены —
решить со специалистом.

## Связь со школьной программой

Мост уже заложен: в ABA.md есть ступень «Шаг к учёбе» (цифра и буква по названию, цифра ↔ количество). Её продолжают
темы подготовительного и 1 класса. Темы 2–4 классов в основном словесные и абстрактные — в ABA-задания почти не
переводятся; для детей, которые до них дорастут, — обычные уроки с адаптацией.

| Навык (как задание) | Школьная тема, класс | Что нужно до него |
|---|---|---|
| Найти такую же картинку из 2–3 | предпосылка | знакомство с жетонами |
| Такая же форма, такой же цвет | «Фигуры», 1 кл. | одинаковые из 3 |
| Похожее, но не такое же (рисунок → фото) | классификация, подг. | одинаковые из 3 |
| Показать названное из 3 («Покажи мяч») | словарь, подг. | отклик на голос |
| Разложить на две группы (живое / неживое) | «Живое и неживое», подг. | показ по названию |
| Одинаковые цифры и буквы | «Цифры», «Буквы», подг. | форма из 3 |
| Цифра по названию («Покажи три») | «Цифры до пяти», подг. | одинаковые цифры |
| Количество ↔ количество 1–3 | «Один, два, три», подг. | похожее, но не такое же |
| Количество ↔ цифра 1–5, потом 0–10 | «Цифры», «Ноль», подг. | цифра по названию |
| Счёт предметов (засчитывает взрослый) | «Считаем до десяти», подг. | количество ↔ цифра 1–5 |
| Буква по звуку, первый звук слова | «Буква и звук», подг. | одинаковые буквы |
| Слог и слово ↔ картинка | «Читаем слоги», 1 кл. | все буквы слога |
| Было и стало (+1, −1 предметами) | «Было и стало», 1 кл. | цифры 0–10 |

**Из «Мира чисел» годится:** предметы для счёта и точки, немые карточки цифр, пустая корзинка для нуля, порядок навыков.
**Переделать:** одно действие на экран вместо трёх пар; одна короткая постоянная инструкция («Покажи три»); убрать
текстовые подсказки и сюжет перед заданием; **убрать Tali, который нарочно ошибается** — ребёнок с РАС может это
скопировать. **Не годится:** задание «разложи по порядку», панорама, атлас.

**Когда переходить на школьные темы** — не по возрасту, а когда освоены предпосылки (похожее, показ по названию,
сортировка, цифра ↔ количество 1–3) и ребёнок выдерживает 10 минут с доской жетонов. Родителю показывать связь
так: «Освоено 6 из 12 навыков подготовительного класса по математике» — без «отстаёт на N лет».

**Где школа спорит с ABA:** темп (в школе — по календарю, в ABA — до освоения), длинные инструкции, оценки за ошибки,
абстракции (больше-меньше, время, лево-право, мораль), перенос (при РАС его надо учить отдельно), ответ словом (многие
дети не говорят — нужен вариант касанием).
