# Шаг «коснись картинки» и раздел специалиста — спецификация (методист-агент, 2026-11-18)

## А. Шаг «коснись картинки» (решение 1, часть В)
- **Кто проходит.** Каждый ребёнок, один раз, до первой пробы `match`; только «Со взрослым». В «Сам» шаг не идёт, а цели
  `match` ребёнку с непройденным шагом не планируются. Отдельной проверки нет: первые 5 самостоятельных касаний подряд —
  шаг пройден. Профили без `sampleTouch` — шаг не пройден, без миграции.
- **Проба.** На экране только образец, инструкция «коснись». Лестница подсказок без L2:
  - L0 — задержка по полосе;
  - L1 — метка над образцом;
  - L3 — модель: экранная рука касается образца;
  - L4 — просьба к взрослому через панель (`promptLevelUsed: 4`).

  Не больше трёх предъявлений в пробе. Затухание — по общему правилу, стартовый уровень хранится в `sampleTouch`.
  «Была подсказка» делает пробу подсказанной.
- **Последствия.**
  - L0 — жетон (причина `'observing'`, `nonContingent`);
  - L1–L3 — знак «принято»;
  - L4 — ничего;
  - `l4_resisted` — шаг на сегодня кончается.
- **Ступень доски.** Обмены шага «бесплатные», как `freeExchanges`: ступень не растёт. Сессия только с касаниями для
  ступени нейтральна.
- **Объём.** Не больше 10 проб шага за сессию. «5 подряд» — внутри сессии; после сворачивания приложения сессия та же.
  - Шаг не пройден — `match` в этой сессии не идёт, остальное идёт. Нет ничего — конец на успешной пробе.
  - 3 сессии без прохождения — флаг `sample_touch_not_acquired`, шаг продолжается; флаг снимается прохождением.
  - Остановка взрослым и ошибка приложения не считаются.
- **Связь со срезом А.** Второй промах наблюдения в измерении закрывает измерение и возвращает ребёнка к шагу; ступень
  не откатывается. `observingMissSessions` растёт по-прежнему. Если после повторного шага измерение снова закрыто
  промахами (счётчик = 2), срабатывает `startAfterObservingMisses` — обучение с L1.
- **Взрослому.**
  - Событие `observing_not_established`: «Картинку сверху на проверках часто пропускали, поэтому дальше учим с меткой над
    ней — ждите молча, подсказку покажет приложение».
  - Возврат к шагу: «Сначала снова потренируем касание картинки сверху — ждите молча, подсказку покажет приложение».

## Б. Раздел «Для специалиста» (взрослая часть, под PIN, телефон семьи, без сети)
- **Задаёт:**
  - `paramsBand`, `timeLimitMs`, `responseWindowMs` по формату, `maxTeachingTargets` (`abaSessionParams.ts`);
  - включатель «Награда от взрослого»;
  - наблюдатели с отметкой «обучен».

  Не меняются: критерий, размер блока, потолок задержки, число эскалаций, правила жетонов.
- **Действия:**
  - «Отметить: беспокойство по согласию просмотрено» (`reviewAssentConcern`);
  - «Подтвердить сопряжение» (`confirmPairing`);
  - **«Назначить проверку вперемешку»** — снимает `mixed_not_established`, обнуляет счётчик, блок снова в плане;
  - **«Просмотрено»** для `token_training_stalled`, `pairing_keeps_breaking`, `ioa_low` — снимает флаг; при повторе
    условия он появится снова.
- **Только просмотр:**
  - `position_bias`, `card_preference`, `alternation_bias`;
  - `no_progress`, `prompt_dependent`, `needs_verification`, `needs_transfer`;
  - `break_card_*`, `sample_touch_not_acquired`;
  - ступень доски, стартовые уровни, задержки;
  - события `mixed_no_verdict` и `observing_not_established`.
- **Журнал.** Каждое изменение — событие только на дописывание (`commit.ts`): `{role, поле, было, стало, at}`, без имени.
  Роль «заявленная» (за PIN родителя, не проверена). Смена параметра — линия смены условий на графике отчёта.
  Приватность — `child-privacy-compliance`.

## В. Потолок нейтральных сессий смешанного блока
Отдельный счётчик `neutralNoVerdict`, `noVerdict` не трогает. Две нейтральные сессии подряд, где блок начался и итога не
дал, — следующую сессию блок пропускает, оба слота занимает обучение, счётчик обнуляется. Флага нет. В событие
`mixed_no_verdict` пишется `yielded: true`. Сбрасывает счётчик любая сессия с итогом или засчитанная без итога.
