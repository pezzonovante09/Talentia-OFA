# Озвучка ABA: что записать (русский)

Для 4 целей «найди такую же» и для знакомства с жетонами (сопряжения). Обновлено 2026-11-12 (№195).

## Куда класть и как подключить

1. Файл назвать ключом из таблицы: `abaSession.sound.praise.m4a`. Формат — `.m4a` или `.mp3` (`.wav` тоже можно).
   Моно, без тишины в начале и в конце, ровная громкость у всех файлов.
2. Положить в `talentia-mobile/assets/audio/aba/`.
3. Выполнить в `talentia-mobile`: `npm run audio:register` (или написать мне). Скрипт сам впишет файлы в список; если имя с
   опечаткой — предупредит.
4. Собрать новую preview: звук входит в сборку. В браузере (`expo start --web`) можно послушать раньше.

Ключ без файла молчит, как сейчас: записывать можно по одному.

## 1. Звучат, как только есть файл

| Ключ | Что это | Когда звучит | Длина |
|---|---|---|---|
| `abaSession.sound.token` | звук жетона, **не голос** (короткий «дзынь») | жетон упал в ячейку доски — в занятии и в знакомстве | ≤ 0,25 с |
| `abaSession.sound.praise` | голос: «Молодец!» | после ответа, за который положена похвала; вместе с жетоном и без него | **≤ 0,8 с** вместе с хвостом — иначе наложится на следующий кадр |
| `abaSession.sound.invite` | приглашение вернуться из перерыва; текст в документах не задан — предлагаю «Возвращаемся!», как на кнопке | перерыв кончился, ребёнок не вернулся; звучит до двух раз | ≤ 1,5 с |
| `abaSession.sound.wrapUp` | мягкий звук «закругляемся», **не голос** | за 5 с до конца времени с наградой | ≤ 1 с |
| `firstRun.callAdult` | голос: «Позови взрослого» | первый экран: при входе и когда ребёнок нажал свою карточку (в сборке ABA это главный экран ребёнка) | ≤ 1,5 с |

`abaSession.sound.listened` («Tali послушал») записывать не нужно: он для голосовых заданий, их в первой версии нет.

## 2. Ребёнок видит текстом, но голосом сейчас не звучат

| Ключ | Текст на экране | Где |
|---|---|---|
| `aba.sd.matchSame` | Найди такую же | инструкция задания |
| `aba.sd.matchWhere` | Где такая же? | инструкция задания, второй вариант |
| `abaSession.chooseTitle` | За что играем сегодня? | выбор награды |
| `abaReinforcement.token` | Держи жетон! | плашка с жетоном |
| `abaBreak.return` | Возвращаемся | кнопка в перерыве |
| `abaSession.endedToday` | Закончили на сегодня | конец занятия |
| `abaSession.done` | Готово | кнопка в конце |

Чтобы они зазвучали, нужна правка экранов — это не «положить файл». **Инструкцию задания озвучивать — вопрос к
специалисту** (вопрос 9 в `meeting-questions.md`). Время ответа считается от касания образца до выбора — оно не
изменится; а время до касания образца сейчас считается от появления задания и при озвучке будет считаться от конца
звука. Процедуру меняем только после ответа специалиста. Записать файлы заранее можно — подключим, когда будет решение.
