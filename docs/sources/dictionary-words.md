# Словарные слова, 1–4 классы — ждёт списка

**Статус: ждёт списка от владельца** (решение №51, 2026-10-02).

В предметном стандарте КР «Русский язык и чтение» (КАО, 2022) словарного минимума нет —
везде «согласно минимуму» (с. 26–27; `russian-1-4.md`). Без списка уроки «Словарные слова»
(Побережье слов, полоса 8, тема «Проверяем букву», навык `dictionary-words-2`) не пишутся, и
слова не придумываются: выдуманный список научит не тем словам, что проверяет школа.

Пока список не лежит здесь, хук `.claude/hooks/dictionary-words-reminder.js` напоминает об
этом при правке контента Побережья. Когда список появится — заполнить таблицу ниже, удалить
хук (файл и запись в `.claude/settings.json`) и эту строку статуса.
