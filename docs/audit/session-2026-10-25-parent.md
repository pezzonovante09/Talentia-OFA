## Что важно знать новой сессии

- **Web-прототип — ворота прототипа, не выпуск.** `expoSqlite.web.ts` (sql.js, снимок базы в `localStorage`)
  и `talentia:web-secure:*` в AsyncStorage существуют только ради проверки в браузере; Metro берёт `.web.ts`
  сам, Jest и нативные сборки этот файл не видят. В выпуске раздел на web не показывается (PARENT.md «Web»).
- **Metro на этой машине**: падает с `heap out of memory` при ~3 ГБ свободной памяти — `.claude/launch.json`
  теперь запускает `node --max-old-space-size=4096 node_modules/expo/bin/cli`; если и этого мало — 8192 через
  `NODE_OPTIONS`. Наблюдатель файлов иногда умирает (пересборки «1 module» после правок) — тогда перезапуск.
- **`expo-sqlite` в `node_modules` был без `web/wa-sqlite/*`** (неполная установка) — переустановлен; на web
  всё равно не работает из-за Worker по адресу страницы, поэтому `sql.js`.
- **Сброс гейта при выходе** — cleanup эффекта `Guarded`; тест `app/parent/__tests__/gate.test.tsx`. Окно
  свежести 5 минут действует только внутри открытого раздела (смена полосы без листа PIN сразу после входа —
  по замыслу).
- **Удаление аккаунта**: сначала `router.replace('/parent/done')`, потом `clear()` и `lock()` — иначе гейт при
  `status: 'none'` успевал увести в настройку; `confirm/delete_account` поэтому в `OPEN_WITHOUT_ACCOUNT`
  (без аккаунта и вне удаления экран сам редиректит в настройку). «К выбору профиля» — `replace('/')`.
- **Отчёт** (`src/state/parentView.ts`): `lessonRunsOf` + `child_state.skills` → `buildParentReport`; всё в
  памяти, слова вместо процентов. Метка «повторов» — короткая, чтобы входить в четыре колонки на 390.
- Ошибки обработчиков показываются строкой `parent.failed`; в dev ещё и `console.warn` (`setup`, `consent`,
  `profile`, `confirm`, `boot`).

## Открыто — ждёт владельца

- **Срок хранения по часам устройства** (№131): `applyRetention` на старте необратимо удаляет прохождения
  старше 12 месяцев по времени устройства — ребёнок, переведя дату «ради игр», сотрёт прогресс всем детям
  (`purge.ts` описывает риск). `child-privacy-compliance` предлагает нижнюю границу датой сборки и запрет
  удаления при скачке больше года без подтверждения; техническое решение — `backend-auditor`. Вопрос 39.
- **Осиротевшие базы**: сбой `boot` (битая база) → `clear()` → повторная настройка создаёт второй аккаунт;
  файл и PIN старого остаются и «Удалить аккаунт» их не находит. Предложение — стирать все `talentia-*.db` и
  `talentia.*.pin` без привязки к текущему id. Вопрос 40.
