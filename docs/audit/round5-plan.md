## Порядок запуска

1. Семь агентов параллельно одним сообщением; `design-lead` можно в том же сообщении.
2. `child-ux-specialist` — после отчёта `design-lead`, с его итогом на входе.
3. Сводка единым списком (приватность выше производительности), противоречия — владельцу.
4. Запись через скилл `rebuild-log`: блок «Аудит пересборки, раунд 5» в AUDIT.md, отчёт
   `docs/audit/round5-<дата>.md`, раунд в `.claude/audit-gate.json` (правка файла — с подтверждением
   владельца, №118).
5. При 0 блокеров ворота открываются: следующий шаг — контент пилота и экран прогона ABA для родителя;
   один раз предложить скиллы `format-screen` и `asset-pipeline`.
