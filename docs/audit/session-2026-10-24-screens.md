## Что важно знать новой сессии

- **Поток экрана урока**: `app/lesson/[lessonId].tsx` → `useLessonController` (фазы `answer` → `locked`
  0…1040 → сужение / `shownWait` → `done`; «Дальше» через 900 после верного) → `FORMATS[format]`
  (`emptyDraft` / `tap` / `answerOf` / `afterNarrowing` / `shown` / `wrongOf` / `correctedOf`). Орекстратор
  — единственный судья ответа; экран только собирает черновик.
- **Голос** — `src/services/voice.ts`, `silentVoice`: экраны уже зовут `voice.say(key)` в нужных местах
  (вопрос при открытии, элемент по тапу, подсказка, объяснение, реплики карты). Озвучка — этап 13.

  реплики похвалы и ситуаций появятся с банком (этап 12), адаптер `situationOf` ещё не написан.
- **Перечисление с подсветкой** (`listeningCue`) идёт по таймеру 700 мс на элемент — без голоса это
  условность; с озвучкой длительность берётся из аудио.
- **Карта**: `router.navigate('/map')` из урока и атласа возвращает к карте в стеке (replace плодил вторую).
- Сеть закрыта ESLint; `expo-crypto`, `@expo-google-fonts/comfortaa`, `@testing-library/react-native`
