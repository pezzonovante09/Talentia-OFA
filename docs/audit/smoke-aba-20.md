# Проверка ABA на телефоне: 20 шагов

Первая проверка версии «только ABA, со взрослым» на Android-телефоне: от установки до файла для специалиста. Сборка — preview с режимом «только ABA», компьютер не нужен; старая preview от 5 ноября не подойдёт: в ней нет картинок к заданиям и есть карта с уроками.
Время — около часа. Понадобятся бумага и ручка для PIN, калькулятор, второй телефон для звонка (шаг 18), мессенджер или почта на этом телефоне (шаг 20). Детям сборку не давать, настоящие данные не вводить.
В занятиях отвечайте верно и без пауз: верхнюю плитку, сразу такую же внизу. Молчание дольше 5 секунд считается ошибкой и удлинит проверку.
**Правило остановки:** если в шаге 6 или 12 данные не пережили закрытие или перезагрузку — дальше не идите, пришлите результат в чат.

|---|---|---|---|
| 1 | Удалите все старые Talentia. Откройте на телефоне ссылку на сборку, скачайте и установите файл (на предупреждение защиты — «Всё равно установить»). | Приложение установилось, на экране телефона есть иконка Talentia. | |
| 2 | Откройте приложение. | Заставка, затем «Позови взрослого»: Tali, карточка с плюсом, внизу «Для взрослых». Кнопки «Попробовать без сохранения» нет. Русские буквы без квадратиков, ничего не залезает под панели телефона. | |
| 3 | Нажмите «Для взрослых» и пройдите настройку: решите пример на калькуляторе и введите ответ кнопками на экране, придумайте PIN из 6 цифр (запишите на бумагу), повторите его, «Продолжить». | Клавиатура телефона не выезжает, цифры PIN на экране перемешаны. После повтора — «Шаг 4 из 4», после «Продолжить» — «Новый профиль», ошибки «Не получилось» нет. | |
| 4 | Впишите имя «Тест», выберите полосу 5–6, «Создать профиль». | Поле видно над клавиатурой, русские буквы печатаются. После создания — первый экран с карточкой «Тест». | |
| 5 | Нажмите карточку «Тест». | Заголовок экрана — «Позови взрослого». Карта с уроками не открывается: сразу ввод PIN. После верного PIN — «Занятия ABA» ребёнка «Тест». | |
| 6 | Закройте приложение совсем (смахните из списка недавних) и откройте снова. | Карточка «Тест» на месте, настройку заново не спрашивает. **Не так — дальше не идите.** | |
| 7 | «Тест» → PIN (откроются «Занятия ABA») → «Прочитать согласие» → «Согласен» (попросит PIN — введите). | До согласия — «Нужно согласие на данные практики». После — «Сначала знакомство с жетонами…», «Кто ведёт» — «Не выбрано», кнопка «Начать знакомство». Переключателя «Со взрослым» / «Сам» нет: режим только «Со взрослым». Если вместо этого «Цели ждут картинок» — сборка собрана без картинок к заданиям: дальше не идите, пришлите снимок экрана. | |
| 8 | «Начать знакомство». В листе выберите «Родитель», включите «Прошёл обучение у специалиста», «Готово». Снова «Начать знакомство». | Лист «Кто ведёт занятие?» помещается целиком, в строке — «Родитель · обучен». После второго нажатия сразу песочный экран «За что играем сегодня?» с тремя карточками наград; карта не мелькает, экран не белый. | |
| 9 | Выберите карточку и пройдите знакомство до конца: 4 круга, около 3 минут. В середине один раз нажмите системную «Назад». | В каждом круге: 10 секунд ожидания, жетон въезжает в ячейку и летит в карточку, она раскрывается в награду на весь экран с убывающим кольцом сверху (около 20 секунд). «Назад» ничего не делает. В конце Tali, «Закончили на сегодня», «Готово» — оно ведёт на первый экран с карточкой «Тест», не на карту с уроками. | |
| 10 | «Тест» → PIN → «Занятия ABA». Если снова предлагает знакомство — «Знакомство с жетонами уже пройдено». «Начать занятие» и пройдите обучение карточке «перерыв»: на каждую просьбу панели касайтесь карточки, потом «Возвращаемся» (три раза). | Справа вверху карточка «перерыв» с двумя полосками, внизу панель взрослого с «Пропустить» — целиком выше системных кнопок. Касание карточки открывает перерыв: полоски в убывающем кольце, внизу «Возвращаемся». После обучения — «За что играем сегодня?». | |
| 11 | Выберите награду и ответьте верно на все 5 заданий. На первом сначала нажмите нижнюю плитку, потом верхнюю, потом такую же внизу. | Пока не нажата верхняя, нижние приглушены и не отвечают. После ответа жетона нет — так и должно быть в первом занятии; через 5 секунд следующее задание. В конце ожидание с Tali, жетон летит в карточку, награда, «Закончили на сегодня». Плитки и панель не обрезаны. | |
| 12 | Перезагрузите телефон. Откройте Talentia → «Тест» → тот же PIN → «Занятия ABA». | Профиль, PIN и согласие на месте, «Можно начинать». В «Цели» подпись «Занятие сегодня: проб — 5, самостоятельно — 5» (если ошибались, числа другие, но пробы записаны). **Не так — дальше не идите.** | |
| 13 | «Начать занятие», выберите награду и отвечайте верно до конца (около 13 заданий, 3 минуты). Где активна одна нижняя плитка — это подсказка, нажмите её. | Занятие доходит до «Закончили на сегодня» с Tali. Плашки «Держи жетон!» может не быть или она одна в конце. К последнему заданию плитки откликаются так же быстро, как в начале. Обрыв посреди занятия без Tali — ошибка, сделайте снимок экрана. | |
| 14 | «Тест» → PIN → «Занятия ABA» → «Начать занятие», выберите награду. Ответьте верно и быстро: верхняя и за секунду такая же внизу. | Фиолетовая плашка с Tali и «Держи жетон!», жетон падает в ячейку, меньше чем через секунду летит в карточку, и она раскрывается в награду — всего около 3 секунд, без пустых кадров. Вышла подсказка — ответили медленно, повторите на следующем задании. Задания кончились раньше шага 19 — начните новое занятие и продолжайте с того же шага. | |
| 15 | На следующем задании коснитесь карточки «перерыв». Ждите, пока у «Возвращаемся» не появится толстая рамка, и нажмите её. | Экран перерыва: полоски в убывающем кольце; через 15 секунд кольцо кончается, у «Возвращаемся» толстая рамка. После нажатия — снова задание, занятие продолжается. | |
| 16 | На следующем задании нажмите «Отказ» внизу справа. | Нажимается с первого раза, системный жест не срабатывает. Плитки исчезают, у карточки «перерыв» толстая рамка 30 секунд, первые 10 секунд в панели «Покажите на карточку жестом, не уговаривайте». Потом занятие продолжается. | |
| 17 | На задании, ничего не нажимая, запомните предметы на плитках. Сверните приложение кнопкой «Домой», через 30 секунд вернитесь из списка недавних и ответьте верно. | То же задание с теми же плитками, старый кадр не мелькает. Время в фоне не засчитано как молчание: ответ принят, занятие идёт дальше. | |
| 18 | На задании попросите позвонить вам со второго телефона. Сразу примите звонок, поговорите 20–30 секунд, положите трубку; если Talentia не вернулась сама — откройте её из недавних. Ответьте верно. | Приложение не перезапустилось: то же задание с теми же плитками, ответ принят, занятие идёт дальше. Если пока телефон звонил, вышла подсказка, — запишите, сколько секунд он звонил. | |
| 19 | Отвечайте верно до конца занятия. | Занятие доходит до «Закончили на сегодня» с Tali, без обрыва посреди; этот экран появляется один раз. «Готово» ведёт на первый экран, не на карту с уроками. Системная «Назад» на первом экране сворачивает приложение с первого нажатия (если тот же экран показался ещё раз — запишите). | |

Файл с названием «talentia-aba-» и сегодняшней датой дошёл, его размер не нулевой, внутри текст без имени «Тест». После возврата приложение снова просит PIN — это норма. | |
