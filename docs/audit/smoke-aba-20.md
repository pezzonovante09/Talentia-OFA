# Проверка ABA на телефоне: 20 шагов

> **Полный гайд с отметками, пояснениями и отчётом** — `docs/audit/phone-test-guide-2026-11-13.html` (открыть в Chrome
> или Edge): сборка, установка, эти 20 шагов, 7 наград, кнопки, тёмная тема, спокойный режим, звук. Шаги берутся из
> этого файла. Сверено с кодом 2026-11-13 (`qa-engineer`: прогон домена на 6 занятий; `child-ux-specialist`).

Первая проверка версии «только ABA, со взрослым» на Android-телефоне: от установки до файла для специалиста. Сборка — preview с режимом «только ABA» (`npm run build:aba`), компьютер во время проверки не нужен.
Время — около часа. Понадобятся бумага и ручка для PIN, калькулятор, второй телефон для звонка (шаг 18), мессенджер и почта на этом телефоне (шаг 20). Детям сборку не давать, настоящие данные не вводить.
В занятиях отвечайте верно и без пауз: сначала верхняя плитка, потом такая же внизу. На каждое касание около 5 секунд. Выход из занятия — только удержанием стрелки слева вверху 1,5 секунды; кнопка «Назад» телефона в занятии не работает.
**Правило остановки:** если в шаге 6 или 12 данные не пережили закрытие или перезагрузку — дальше не идите, пришлите результат в чат.

| № | Шаг | Что должно быть | Что я увидел |
|---|---|---|---|
| 1 | Удалите все старые Talentia. Откройте на телефоне прямую ссылку на `.apk`, скачайте и установите файл (на предупреждение защиты — «Всё равно установить»). | Приложение установилось, на экране телефона есть иконка Talentia. | |
| 2 | Откройте приложение. | Заставка, затем «Позови взрослого»: Tali, карточка с плюсом, внизу серая строка «Для взрослых». Кнопки «Попробовать без сохранения» нет. Русские буквы без квадратиков, ничего не залезает под панели телефона. | |
| 3 | Нажмите «Для взрослых» и пройдите настройку: решите пример на калькуляторе, введите ответ кнопками на экране, «Дальше»; придумайте PIN из 6 цифр (запишите на бумагу), повторите его; на экране «Шаг 4 из 4» нажмите «Даю согласие». | Клавиатура телефона не выезжает, цифры PIN на экране перемешаны, после шестой цифры экран сам идёт дальше. После «Даю согласие» — «Новый профиль», ошибки «Не получилось» нет. | |
| 4 | Впишите имя «Тест», выберите полосу 5–6, «Создать профиль». | Поле видно над клавиатурой, русские буквы печатаются. После создания — первый экран с карточкой «Тест». | |
| 5 | Нажмите карточку «Тест». | Карта с уроками не открывается: сразу экран PIN «Для взрослых». После верного PIN — экран «Занятия ABA». | |
| 6 | Закройте приложение совсем (смахните из списка недавних) и откройте снова. | Карточка «Тест» на месте, настройку заново не спрашивает. **Не так — дальше не идите.** | |
| 7 | «Тест» → PIN → на экране «Занятия ABA» нажмите «Прочитать согласие» → «Даю согласие» (PIN попросит, только если читали дольше 5 минут). | До согласия — «Нужно согласие на данные практики». После — «Сначала знакомство с жетонами…», «Кто ведёт» — «Не выбрано», кнопка «Начать знакомство». Переключателя «Со взрослым» / «Сам» нет. Если вместо этого «Цели ждут картинок» — дальше не идите, пришлите снимок экрана. | |
| 8 | «Начать знакомство». В листе выберите «Родитель», включите «Обучение у специалиста пройдено», «Готово» (справа вверху). Снова «Начать знакомство». | Лист «Кто ведёт занятие?» помещается целиком, в строке — «Родитель · с обучением». После второго нажатия сразу песочный экран «За что играем сегодня?» с тремя **разными** картинками наград; экран не белый. | |
| 9 | Пройдите знакомство: 4 круга, около 3 минут. В каждом круге коснитесь одной картинки (берите разные), потом ничего не нажимайте 10 секунд. В середине один раз нажмите системную «Назад». Приложение не сворачивайте. | В каждом круге: выбор («За что играем сегодня?», дальше «За что играем теперь?»), 10 секунд неподвижного ожидания, жетон въезжает в ячейку и летит в картинку, она раскрывается в игру-награду на весь экран с убывающим кольцом сверху (около 20 секунд), награда кончается сама. «Назад» ничего не делает. В конце Tali, «Закончили на сегодня», «Готово» (с галочкой) ведёт на первый экран. | |
| 10 | «Тест» → PIN. Статус снова «Сначала знакомство…» — нажмите тихую строку под кнопкой: «Знакомство с жетонами уже пройдено». Затем «Начать занятие» и пройдите обучение карточке «перерыв»: три раза коснитесь квадрата с двумя полосками справа вверху (в третий раз — сразу, не выжидая), каждый раз на открывшемся экране нажмите «Возвращаемся». «Пропустить» не нажимайте. | После «уже пройдено» — «Можно начинать». В обучении: справа вверху карточка с двумя полосками, внизу панель взрослого с подсказками («Коснитесь карточки „перерыв“ сами», «Покажите на неё жестом», «Подождите 10 секунд, потом жест») и «Пропустить» — целиком выше системных кнопок. Касание карточки открывает перерыв: полоски в кольце (15 секунд), «Возвращаемся». После трёх раз — «За что играем сегодня?». | |
| 11 | Выберите награду и ответьте верно на 5 заданий с фигурами (три нижние плитки). На первом сначала нажмите нижнюю плитку, потом верхнюю, потом такую же внизу. | Пока не нажата верхняя, нижние в штриховку и не отвечают. Фигуры коричневые, различаются только формой, у кольца есть обводка. После ответа жетона нет — так и должно быть в первом занятии; через 5 секунд следующее задание. В конце 10 секунд ожидания с Tali, жетон летит в картинку, награда 20 секунд, «Закончили на сегодня». Плитки и панель не обрезаны. | |
| 12 | Перезагрузите телефон. Откройте Talentia → «Тест» → тот же PIN. | Профиль, PIN и согласие на месте, «Можно начинать». В «Целях» подпись «Занятие сегодня: проб — 5, самостоятельно — 5» (если ошибались, числа другие, но пробы записаны). **Не так — дальше не идите.** | |
| 13 | «Начать занятие», выберите награду и отвечайте верно до конца: 13 заданий, около 3 минут. Если после касания образца светлая только одна нижняя плитка — это подсказка, нажмите её. | Задания с фигурами, цветами и предметами. **Жетонов и награды в этом занятии нет вообще** — так задумано; в конце сразу «Закончили на сегодня» с Tali. К последнему заданию плитки откликаются так же быстро, как в начале. Обрыв посреди занятия без Tali — ошибка, сделайте снимок экрана. | |
| 14 | «Тест» → PIN → «Начать занятие», выберите награду. Первые два задания — с подсказкой (светлая одна плитка), жетона за них нет. На третьем ответьте верно. | С третьего задания: фиолетовая плашка с Tali и «Держи жетон!», жетон падает в ячейку, меньше чем через секунду летит в картинку, и она раскрывается в награду на 20 секунд — без пустых кадров. Дальше так после каждого верного ответа. Если задания кончились раньше шага 19 — начните новое занятие и продолжайте с того же шага. | |
| 15 | На следующем задании коснитесь карточки «перерыв» (квадрат с полосками справа вверху). Подождите минуту, пока у «Возвращаемся» не появится толстая рамка, и нажмите её. | Экран перерыва: полоски в убывающем кольце; через 60 секунд кольцо кончается, у «Возвращаемся» толстая рамка («Возвращаемся» работает и раньше). После нажатия — снова задание, занятие продолжается. | |
| 16 | После перерыва ответьте верно на два задания. На третьем нажмите «Отказ» внизу справа — один раз. | «Отказ» нажимается с первого раза, системный жест не срабатывает. Плитки исчезают, у карточки «перерыв» толстая рамка, пустой экран 30 секунд; первые 10 секунд в панели «Покажите на карточку жестом, не уговаривайте». Потом занятие продолжается. (Второй «Отказ» за занятие или «Отказ» сразу после перерыва заканчивают занятие — это норма.) | |
| 17 | На задании, ничего не нажимая, запомните картинки на плитках. Сверните приложение кнопкой «Домой», через 30 секунд вернитесь из списка недавних и ответьте верно. | То же задание с теми же плитками, старый кадр не мелькает, PIN не спрашивает. Время в фоне не засчитано как молчание: ответ принят, занятие идёт дальше. | |
| 18 | На задании попросите позвонить вам со второго телефона. Сразу примите звонок, поговорите 20–30 секунд, положите трубку; если Talentia не вернулась сама — откройте её из недавних. Ответьте верно. | Приложение не перезапустилось: то же задание с теми же плитками, ответ принят, занятие идёт дальше. Если пока телефон звонил, вышла подсказка, — запишите, сколько секунд он звонил. | |
| 19 | Отвечайте верно до конца занятия. Когда сам появится экран перерыва (плановый) — нажмите «Возвращаемся». | Плановый перерыв: кольцо 60 секунд и «Возвращаемся». Занятие доходит до «Закончили на сегодня» с Tali, без обрыва посреди; этот экран появляется один раз. «Готово» первую секунду не нажимается, потом ведёт на первый экран, не на карту. Системная «Назад» на первом экране сворачивает приложение с первого нажатия. | |
| 20 | «Тест» → PIN → прокрутите «Занятия ABA» вниз → «Выгрузить для специалиста». Отправьте себе **дважды**: в мессенджер и на почту. Откройте оба полученных файла. | «Готовится…», окно выбора приложения. Оба файла с названием «talentia-aba-» и сегодняшней датой дошли, их размер не нулевой, внутри текст без имени «Тест». После возврата приложение снова просит PIN — это норма. Пустой или не прикрепившийся файл — запишите, в каком приложении. | |
