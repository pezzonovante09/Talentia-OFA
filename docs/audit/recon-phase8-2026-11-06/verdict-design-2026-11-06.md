# Вердикт `design-lead` по фазе 8 ABA (2026-11-06)

**Идея одной фразой.** Незаконченное занятие у родителя получает два честных состояния — «не закончено, можно
продолжить» и «прервано, закройте» — а ребёнок при возврате не видит ни приветствия, ни индикатора: первый кадр
— сразу рабочий. Правки документов направления сделаны агентом (`parent-aba-2026-11-01.md`,
`aba-screens-2026-10-25.md` раздел 1, §2.6, Ц2.11; `aba-screens-review-2026-10-25.md` п. 6).

## Решения

1. **(з) Два состояния карточки.** `in_progress` (< 30 мин, тот же день): «Занятие не закончено», «Режим»,
   `primary` «Продолжить занятие» + `quiet` «Закончить без продолжения» (`adult_stopped`, момент ухода).
   `in_progress_stale` (≥ 30 мин или другой день, `abaBlockOf` отдаёт раньше `in_progress`): статус «Занятие
   прервано — закройте его, чтобы начать новое», «Режим», **одна кнопка `secondary` «Закрыть занятие»**
   (`app_backgrounded`, момент ухода) → `reload()` → обычная карточка с сегментами, «Кто ведёт» и «Начать». Прямого
   `begin()` из stale нет. В статусе нет числа «30 минут» и слова «ошибка». Высоты: stale 224, свежее 258.
2. **(г2) Пауза с незаконченным занятием.** `caption` `textMuted`, `lines={2}`, под статусом «На паузе» через
   `parentSpacing.xs`; текст «Незаконченное занятие ждёт снятия паузы». Кнопка — как у `paused`; «Режим» не
   показываем. Контраст 6.8:1 / 5.7:1.
3. **(к) Гейт `/aba` — через него оба пути:** `begin()` → `/aba` или `/aba?mode=pairing`, `resume()` → `/aba`.
   Тип `goChild` → `'/aba' | '/aba?mode=pairing'`. Экран «слишком мал» в одном месте; `session.tsx` при
   `tier === null` → `replace('/aba')`. Гейт ничего не фиксирует: тир — один раз в `session.tsx` (`tierRef`).
   Тёплый возврат через гейт не идёт. Ожидания в `aba.test.tsx` 201, 212, 345, 358, 392, 425, 666–701 меняются.
4. **(а3)** Заголовок прежний `abaSession.chooseTitle`. **(а6)** Удержание `fromFullBoard.holdMs` 1000 — применять
   при повторном показе обмена; вход `cut`, в calm то же. **Порядок кадров подтверждён:** < 2 мин — та же проба со
   стартового уровня, переходного кадра нет; 2–30 мин — выбор → (перерыв: кольцо с остатком / «Вернуться», срок от
   возврата) → одна высоковероятная проба → та же проба; голова `access` без начала — обмен заново с удержанием →
   доступ. Между возвратом и первым кадром — только `c.background`; `busy` — пустой фон. ≥ 30 мин / другой день —
   `dismissTo('/map')`.

## testID

`aba-close-stale` (кнопка stale), `aba-paused-in-progress` (подпись под паузой). Существующие остаются:
`aba-status`, `aba-mode-row` / `aba-mode-row-value` (и в stale), `aba-continue`, `aba-finish`, `aba-start`,
`aba-config` / `aba-too-small`.

## Открытое для владельца

Кнопка stale — `secondary` «Закрыть занятие» вместо планового `quiet` «Закончить без продолжения». Если владелец
предпочтёт одну кнопку на оба состояния — убрать ключ `closeStale`, использовать `finishWithout` с `quiet`.
