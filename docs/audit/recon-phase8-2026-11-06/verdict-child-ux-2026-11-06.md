# Вердикт `child-ux-specialist` по фазе 8 (кадры возврата), 2026-11-06

**Одной строкой:** блокеров нет; направление `design-lead` и методиста по детским критериям проходит. Три
поправки к модели `sessionResume.ts` (кольцо перерыва, кадр после T, вариант «Закончили» на холодном старте) и одно
расхождение с текущим кодом (`busy` рисует прежний кадр, а не пустой фон) — «важно», не блокер.

## По пунктам

1. **Тёплый возврат < 2 мин — без блокера.** Та же проба со стартового уровня — понятный кадр; SD — событие пробы.
   Условие: входить через `show(step)`, чтобы `pauseBeforeMs` отработал; `frameShownAt` = момент возврата, иначе
   касание, которым ребёнок открывал приложение, засчитается как ответ.
2. **Возврат 2–30 мин — без блокера, «важно».** На каждом кадре одно решение. Слабое место — кольцо перерыва сразу
   после выбора: при `shownAt` = возврат кольцо нарисуется полным и ребёнок прочитает «перерыв начался заново» →
   поправка А. Остаток ≤ 5 с — кольца нет, сразу приглашение. Звук `invite` допустим (событие, не приветствие).
3. **Возврат в доступе — без блокера, «важно».** До T — сцена с кольцом на реальном остатке. После T прямой переход
   выглядит как «игрушка исчезла» (триггер «где моё» при РАС). Минимально достаточно — последний кадр Ц3.5:
   карточка 160 с контуром на `endSettleMs` 1000 от возврата, затем следующий шаг; запись (отрезок до `leftAt`)
   не трогается. Расходится с `design-lead` («сразу следующий шаг») — **решение владельца**.
4. **Обмен, которого не видел — без блокера.** Удержание 1000 → полёт → «получено» → раскрытие ≈ 2.1–2.3 с; в calm
   удержание не сокращать.
5. **Хвост конца — без блокера, «важно».** На `wait` ребёнку ничего не обещали; грустного сигнала у `AbaEnd` нет.
   Риск: `endView` по умолчанию `neutral` — на холодном старте хвоста «Закончили» без Tali при успешной сессии →
   поправка В.
6. **Экран «слишком мал» — без блокера.** Достижим только через родителя; улучшение — блокировка касаний 500–1000 мс
   после появления (как `abaEndDone.lockMs`).
7. **Пустой фон до первого кадра — без блокера при бюджете.** Тёплый ≤ 300 мс, потолок 1000 мс, без спиннера.
   **Расхождение с кодом:** `busy` рисует `lastBody.current` с `pointerEvents="none"`, а Ц2.11 требует пустой фон: при
   `rechoose` мелькнёт старая проба → поправка Г.
8. **Родительская карточка — без блокера.** Улучшение (к `design-lead`/`localization-qa`): подпись под паузой «ждёт
   снятия паузы» обещает продолжение, а при просрочке будет «прервано — закройте»; нейтральнее «Есть незаконченное
   занятие — после снятия паузы».

## Поправки к модели `sessionResume.ts`

- **А. `'break'`:** `startedAt` (из снимка, для доли кольца) и `shownAt` (момент возврата, для правила касания и
  срока бездействия). `until − now ≤ 5000` или вышел — вход с `invite: 1, inviteAt: now`, кольца нет.
- **Б. `'end_access'` (после T):** `AccessRun` в стадии `hold` с началом в момент возврата (1000 мс карточка 160),
  затем `done` → следующий шаг. Запись — отрезок до `leftAt`. Решение владельца.
- **В. `tailOnEnd` / холодный старт хвоста:** вариант «Закончили» (`normal` / `neutral`) — из фактов записи
  (`endedOnSuccess`, `tail.completed`), не из умолчания `endView`.
- **Г. Состояние `'away'`** (или флаг у `busy`): на `onLeave` экран рисуется пустым `c.background`, `lastBody` на
  возврате не показывается; `busy` при записи — как есть.
- **Д. `'step'` при `same_trial`:** через `show(step)` (сохраняет `pauseBeforeMs` и путь `save`), `frameShownAt = now`.

## Ограничения для реализации

1. Каждый первый кадр после возврата получает `frameShownAt` = момент возврата.
2. Смена «пустой фон → первый кадр» — только `cut`; при `reduceMotion`/calm всё дальнейшее — смены кадра.
3. Ни одного звука, привязанного к возврату; только событийные (SD, `invite`, обмен); два звука не стартуют в 300 мс.
4. Минимальные длительности: кольцо перерыва ≥ 5 с, иначе приглашение; удержание полной доски 1000 (и в calm);
   кадр конца доступа 1000. Сцена доступа минимума не имеет.
5. Варианты выбора при возврате — из снимка, в том же порядке и на тех же местах.
6. Пустой фон ≤ 300 мс тёплый / ≤ 1000 мс холодный; `useKeepAwake` и панель взрослого — с первым кадром.
7. Refs касаний (`held`, `releasedAt`, `breakTrace`, `fromFullBoard`) сбрасываются на `onLeave`.
8. Экран «слишком мал»: блокировка нажатий 500–1000 мс (улучшение).
