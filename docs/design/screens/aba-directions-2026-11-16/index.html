Два визуальных направления для версии «только ABA, со взрослым»

Источник — первый тест на Android-телефоне 2026-11-15 (№199): «дизайн крайне сырой, прям отталкивает» — цвета, плитки и картинки заданий, экраны взрослого «как анкета», нет цельного стиля. Порядок по №202: design-lead → child-ux-specialist. Оба направления держат раскладку пробы abaLayout без изменений, плиты 120 / 3×96, цели ≥ 60 pt, пустые плиты без украшений, равную площадь и цвет фигур, отдельную зону взрослого и calm. Макеты только светлые (тёмная заморожена, №197).

Идея Один стол с цветной бумагой для всех: язык «Живой гуаши» (контур, подушка, тёплая бумага) распространяется на экраны взрослого, Tali ведёт взрослого по занятию. Светлый спокойный кабинет: каждый смысл — свой мягкий цветной блок, яркое и фиолетовое — только у награды; Tali только там, где смотрит ребёнок.

Шрифты (Google Fonts, кириллица) Rubik 600/700 — заголовки, кнопки, инструкция ребёнку; Nunito 400/700/800 — текст (как сейчас). Golos Text 400/500/600/700 — один шрифт на всё, сделан под русский интерфейс.
Принцип Цельность через один материал. Жизнь вокруг пробы — Tali, тропа этапов, награды, крафтовая панель; сама проба строгая. Снимаем правило «вычитания» для взрослого: контур 2, подушка 3, статичный Tali, жёлтый только как «мы здесь». Цельность через роли цвета. Взрослый экран — 2–3 блока с иконкой и одна залитая кнопка, а не столбец строк. Фиолетовый уходит в награду целиком, действие — глубокий бирюзовый.
Что меняется в токенах parentTokens: фон → #FFF3E3, outline 0→2, cushion 0→3, радиус 12→16/24; новый adultZone #EBDCC6 (+ кромка 3) для панели; шрифт Rubik + пересчёт glyphFit. Детские palettes и abaColors не меняются. Редакция 2: детские tokens.ts не трогаем. Новая светлая палитра в parentTokens (primary #1D6B66, роли блоков, лист #E2E8E6 + кромка #6F7E84) и свои литералы в abaColors.light (фон, детские кнопки #1E2A2F, борт #C7D0CD); плита, стимулы и жетон #FFC42E — как есть. Golos Text — только взрослый раздел и ABA; урок и glyphFit на Nunito.
Риск для ABA Tali и жёлтый на экране «Занятия ABA» могут привлечь ребёнка, если он видит телефон взрослого (экран за PIN, Tali статичен). Тёплая панель не должна звать к нажатию — у её кнопок нет подушки. Закрыт по UX: кромка листа 2 pt #6F7E84 обязательна (3.87 к фону, 3.39 к листу), подпись чернилами 11.85:1 в одну строку, без заголовка «Для взрослого»; обычный режим не задет — primary меняется только у взрослого.
Для кого лучше Семьи и дети 4–7: тепло, персонаж, «книжка-аппликация»; стыкуется с принятыми ассетами (Tali, 7 наград — тот же контур #2A1A12). Специалисты центра и родители, которым важна серьёзность; дети с сенсорной чувствительностью — экран тише уже в обычном режиме.

Рекомендация design-lead до выбора (историческая): А, с одним приёмом из Б

  • А чинит главное — «нет цельного стиля»: один материал на всех экранах и совпадение с уже принятыми ассетами (Tali, награды в контуре #2A1A12); Б с этими ассетами расходится — чернильные стикеры на холодном сером.
  • Из Б взять принцип «блок = смысл» для взрослого: правило шага введения — блоком с иконками, «Где мы сейчас» — отдельной цветной карточкой.
  • Оговорка: если «отталкивают цвета» значит сам тёплый коричнево-бежевый тон, то лучше подходит Б — это решает владелец по макетам на телефоне (открыть HTML в браузере телефона в масштабе 100%).
