# Направление Б «Тихий кабинет» — спецификация переделки (№203)

Источник: первый тест на телефоне (№199), выбор владельца №203, проверка `child-ux-specialist` 2026-11-16. Макет: `docs/design/screens/aba-directions-2026-11-16/b-tihiy-kabinet.html` (редакция 2).

**а. Палитра (светлая).** `parentColors.light`: `background #F4F6F5` · `card #FFFFFF` · `text #1E2A2F` (13.55 / 14.71) · `textMuted #55656B` (5.59 / 6.07) · `primary #1D6B66` + `onPrimary #FFFFFF` (6.27) · `hairline #C9D2CF` (группировка, границу не несёт) · новые `edge #6F7E84` (граница кнопки и кромка листа: 3.87 к фону, 3.39 к листу, 4.20 к белому) · `blockWhere #DDEDE6` · `blockExplain #DCE8F2` · `blockRule #FBE7D3` · `zone #E2E8E6` · `error #BB1E1E` без изменений. `parentPressed.light`: `card #E6EBE9`, `primary #15524E` (белый 8.94). `abaColors.light`: `background #F4F6F5`, `ink` и `controlInk #1E2A2F`, `controlFill #FFFFFF`, новый `controlLip #C7D0CD` (борт 4 / calm 2), `tokenSlot #E6EBEA` с пунктиром 3 `#55656B`, `rewardWindow #ECE6F8`; **не меняются** `plate`, `plateOutline #2A1A12`, `tokenEarned #FFC42E` (выученный подкрепитель), `tokenOutline`, `reinforcement #5A34C4`, `inactiveHatch`. Фиолетовый и лаванда — только награда.

**б. Шрифт Golos Text.** Сейчас стоят `@expo-google-fonts/nunito ^0.4.2` и `expo-font ~14.0.12`; `FONT_FILES` из `src/ui/fonts.ts` грузит `useFonts` в `app/_layout.tsx`. Добавить `npx expo install @expo-google-fonts/golos-text` (если пакета нет — TTF из Google Fonts в `assets/fonts/` через `require`), начертания `GolosText_400Regular / 500Medium / 600SemiBold / 700Bold` в `FONT_FILES`, семейство `'Golos Text'` в `BY_FAMILY`. Nunito остаётся: он нужен замороженному уроку. Метрики: прогнать `scripts/glyph-metrics.mjs` по TTF Golos, получить `GOLOS_LINE_RATIO`; правило — `lineHeight ≥ ceil(size × ratio)`, иначе на Android срежутся Й и Ё. Кегли и интерлиньяжи оставить прежними (слоты 72 / 56 рассчитаны под них), меняются семейство и веса: заголовки 700, кнопки и подписи 600, текст 400, подпись на листе 500. `glyphMetrics` / `glyphFit` — это урок, их не пересчитываем.

**в. Как не задеть обычный режим.** `tokens.ts` не меняется ни на байт. Значения «кабинета» пишутся прямо в `parentTokens.ts` (light) и `abaTokens.ts` (`abaColors.light` — свои литералы вместо ссылок на `palettes.light.normal`, плюс новая `abaTypography`). Флаг `ABA_ONLY` для токенов не нужен: раздел взрослого и ABA — единственные живые зоны версии, второй вид тех же экранов удвоил бы проверку. Флаг остаётся только в `app/index.tsx`: первый экран собран из детских примитивов обычного режима, там ветка `ABA_ONLY` уже есть. Тёмную схему не трогаем (№197). Предложение владельцу: в сборке ABA закрепить светлую схему, иначе телефон в тёмном режиме покажет старую «гуашь».
