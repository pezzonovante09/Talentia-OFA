# Полевой фидбек: ABA-центры, детские сады, специалисты

> **Статус: пусто.** Этот файл — шаблон для трекинга. На момент создания
> (2026-08-15) в репозитории Talentia нет ни одной задокументированной записи
> реального полевого фидбека — только неподтверждённые упоминания вида
> «протестировано в реальном ABA-центре» в `docs/AUDIT_2026-08-06.md` и
> `docs/AUDIT_2026-08-12.md`, без имён, дат, цитат или конкретных замечаний.
>
> **Не заполняй этот файл выдуманными записями.** Каждая строка ниже — это
> реальный человек, реальная дата, реальная цитата или конкретное наблюдение
> за реальным ребёнком/сессией. Если у команды есть заметки из полевого
> тестирования (бумажные, в чате, в презентации, в памяти у кого-то) —
> перенеси их сюда в структурированном виде. Если таких заметок нет —
> оставь файл пустым до следующего реального контакта со специалистом/
> воспитателем/родителем, а не выдумывай правдоподобно звучащий фидбек.

## Как использовать

1. Каждая сессия наблюдения/интервью — отдельная запись в разделе
   «Журнал наблюдений» по шаблону ниже.
2. Каждое конкретное замечание специалиста, которое влияет на контент/код,
   переносится строкой в таблицу «Замечания и статус» с честным статусом.
3. Не смешивай это с внутренними AI-само-аудитами
   (`talentia-mobile/scripts/_curriculum_audit_*.md`,
   `_aba_en_ky_mismatches.md` и т.п.) — это самопроверки кода командой/ИИ,
   а не фидбек от людей вне проекта. Если что-то из внутреннего аудита было
   независимо подтверждено специалистом на реальной сессии — тогда это можно
   зафиксировать здесь со ссылкой на источник.
4. Источник каждой записи должен быть прослеживаем: кто, когда, в каком
   формате (личная встреча, звонок, переписка, наблюдение за сессией).

## Журнал наблюдений

Шаблон одной записи (скопируй блок ниже для каждой новой сессии):

```
### YYYY-MM-DD — <учреждение/контекст>

- **Источник:** <имя и роль специалиста/воспитателя/родителя, либо
  "прямое наблюдение автора записи">
- **Формат:** <очная сессия / созвон / переписка / письменный отчёт>
- **Возраст/профиль детей:** <например, 5 лет, РАС, вербальный>
- **Контекст использования:** <какие темы/уроки проходили, ABA-режим или
  стандартный>
- **Наблюдения:**
  - <конкретное наблюдение 1, с цитатой если есть>
  - <конкретное наблюдение 2>
- **Прямые цитаты специалиста (если есть):**
  - "<цитата>" — <кто сказал>
```

_(пока нет записей)_
