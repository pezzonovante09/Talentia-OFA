`g3m-1000-l1`

1. **Сотни.** 100, 200, 300 … 1000. Число 347 = 3 сотни + 4 десятка + 7 единиц.

**Задания:**
1. **multiple_choice** — Тали взял 3 блока по 100. Посчитай: сколько всего?

   Варианты ответа:
   - `a`: 200
   - `b`: 300 ✓
   - `c`: 400

   Варианты ответа:
   - `a`: 400
   - `b`: 500 ✓

4. **multiple_choice** — Тали копил монеты по 100. Стало 1000. Посчитай: сколько стопок?

   Варианты ответа:
   - `a`: 5

   - `c`: 10 ✓
