# Подключение телефона к Expo (когда tunnel не работает)

## Ошибка "failed to start tunnel" / "remote gone away"

Tunnel (ngrok) может не работать из‑за:
- **Firewall** — блокирует соединение с ngrok
- **VPN** — отключите VPN и попробуйте снова
- **Корпоративная сеть** — ограничения на исходящие соединения

## Решение: использовать LAN вместо tunnel

Телефон и ноутбук должны быть в **одной Wi‑Fi сети**.

### 1. Запуск в LAN-режиме

```bash
npm run start:lan
```

или

```bash
npx expo start --lan
```

### 2. Настройка Windows Firewall

1. Откройте **Параметры Windows** → **Безопасность** → **Брандмауэр Windows**
2. Нажмите **Разрешить приложение через брандмауэр Windows**
3. Найдите **Node.js JavaScript Runtime** и отметьте **Частные** сети
4. Если Node.js нет в списке — **Разрешить другое приложение** → `C:\Program Files\nodejs\node.exe`

Либо создайте правило для портов **19000, 19001, 19002** (входящие TCP).

### 3. Тип сети Windows

Сеть Wi‑Fi должна быть **Частная** (Private), не **Публичная** (Public):

1. **Параметры** → **Сеть и Интернет** → **Wi‑Fi** → ваша сеть
2. **Свойства** → **Профиль сети** → выберите **Частная**

### 4. Отключите VPN

Временно отключите VPN (NordVPN, ExpressVPN и т.п.) и проверьте подключение.

### 5. Подключение телефона

1. Установите **Expo Go** на телефон
2. Отсканируйте QR‑код из терминала
3. Убедитесь, что телефон в той же Wi‑Fi сети, что и ноутбук

### 6. Альтернатива: USB

- **Android**: подключите по USB, включите отладку по USB, запустите `npx expo start --android`
- **iPhone**: подключите по USB, запустите `npx expo start --ios`

### 7. Проверка IP-адреса

В терминале Expo должен быть указан URL вида `exp://192.168.x.x:8081`. Убедитесь, что `192.168.x.x` — IP вашего ноутбука в Wi‑Fi. Проверить IP: `ipconfig` (ищите IPv4 в разделе Wi‑Fi).
