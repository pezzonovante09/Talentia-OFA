## Как ревьюить

1. Открыть урок в приложении (RU, standard).
2. Прочитать диалог → 2 карточки интро → все задания.
3. Отметить: скучно / нормально / цепляет; где спойлер в intro; где сухой список фактов.
4. Для ABA-профиля — те же уроки g1w-bdy-* и выборка Phase 3.

Результаты ревью можно писать прямо в этот файл (колонка «Заметки») или отдельным тредом.
