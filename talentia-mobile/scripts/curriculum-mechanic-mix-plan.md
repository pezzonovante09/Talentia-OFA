# План диверсификации типов заданий (MC → другие механики)

Цель: снизить однообразие, не вводя сразу drag-and-drop. Использовать уже поддерживаемые типы из `src/data/worlds.ts`: `input`, `fill_blank`, `sorting`, `image_point`, `image_word_match`, `routine_chain`, `world_knowledge`.

## Приоритетные зоны

| Зона | Пример уроков | Предлагаемая смена |
|------|-----------------|---------------------|
| Русский 1–2 кл., слоги/буквы | `g1r-vow-l*`, `g2r-sh-l*` | Часть MC → `input` (одна буква/слог) или `fill_blank` в коротком слове |
| Математика 1–2 кл. | `g1m-add-l*`, `g2m-add2-l*` | Уже есть `input`; добавить ещё 1 `input` вместо «лёгкого» MC на конец урока |
| Логика / дошкольный | `meadow-sh-l*`, `garden-col-l*` | «Лишний объект» через `world_knowledge` или второй `sorting`, если появятся группы в данных |
| 3 кл. деление | `g3m-div-l*` | Уже смесь MC + `input`; оставить MC на проверку понимания, `input` на вычисление |

## Эпик «тяжёлые» механики (отдельно)

- Drag-and-drop: новый `TaskType`, hit-testing, доступность.
- Свободное рисование: хранение ответа, оценка — только при методической необходимости.

## Порядок внедрения

1. Выбрать 2–3 урока пилотом, заменить по одному заданию, прогнать `npm run audit:i18n` и ручной прогон урока.
2. Обновить `curricula/grade-*-curriculum-ru.md` (`npm run export:curriculum-grades`) для методистов.
3. Масштабировать по предметам после метрик вовлечённости.
